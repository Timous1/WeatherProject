# Weather Automation & API

A Python weather monitoring project that fetches weather data from OpenWeather, stores it in SQLite, exposes it through a FastAPI REST API, and sends email alerts when configured weather conditions are met.

## Features

- Fetches current weather data for Bratislava
- Stores temperature, pressure, wind speed, and timestamps in SQLite
- Provides weather statistics for a selected time range
- Supports alerts for temperature, pressure, and wind speed
- Sends email notifications when alert conditions are met
- Prevents repeated notifications while an alert condition remains active
- Provides REST endpoints for weather data and alert management

## How It Works

```text
             OpenWeather API
                    │
                    ▼
              Weather Data
                    │
                    ▼
                 SQLite
                /      \
               ▼        ▼
           FastAPI    Alert Engine
                         │
                         ▼
                       Email
```

The weather collector retrieves the latest conditions and stores them in the database. The alert system then evaluates enabled alerts against the new weather data.

When an alert condition is met, an email is sent. The alert is marked as triggered so that additional emails aren't sent while the condition remains true. Once the condition clears, the alert is reset and can trigger again.

## API

### `GET /weather`

Returns all stored weather measurements.

### `GET /stats`

Returns minimum, maximum, and average values for:

- Temperature
- Pressure
- Wind speed

By default, statistics cover the previous 24 hours.

A custom time range can be provided using Unix timestamps:

```text
/stats?from=1750000000&to=1750086400
```

### `POST /alerts`

Creates a new weather alert.

Example:

```json
{
  "email": "you@example.com",
  "location": "Bratislava",
  "metric": "temperature",
  "operator": ">",
  "threshold": 30
}
```

Supported metrics:

- `temperature`
- `pressure`
- `wind_speed`

Supported operators:

- `>`
- `<`
- `>=`
- `<=`

### `GET /alerts`

Returns enabled alerts.

### `DELETE /alerts/{alert_id}`

Deletes an alert by ID.

## Running Locally

Generated by ChatGPT, follow at own risk!

Create and activate a virtual environment:

```bash
python -m venv .venv
```

```bash
# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

Configure the required OpenWeather and email environment variables.

Start the API:

```bash
uvicorn api:app --reload
```

The interactive API documentation is available at:

```text
http://127.0.0.1:8000/docs
```

Run the weather collector with:

```bash
python weather.py
```
